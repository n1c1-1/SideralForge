# OpenNGC

- Files: `NGC.csv.gz` and `addendum.csv.gz` (OpenNGC's `database_files/NGC.csv` and `addendum.csv`, unchanged,
  gzip-compressed), `LICENSE.txt` (OpenNGC's `LICENSES/CC-BY-SA-4.0.txt`).
- Origin: Mattia Verga, https://github.com/mattiaverga/OpenNGC
- Version: release `v20260501` (1 May 2026). Downloaded 2 November 2026.
- Made with: `tools/catalogues/build_objects.py`.
- Licence: CC BY-SA 4.0 (Creative Commons Attribution-ShareAlike 4.0 International), the full text in `LICENSE.txt`.
  Copyright 2023 Mattia Verga. The files are redistributed unchanged (compressed only).
- Used for: the NGC, IC and Messier objects (position, type, axes, position angle, magnitudes, common names, Messier
  numbers, cross-identifications) of the catalogue of named objects (`astro_gpu/core/skyobjects.py`).

## Citation
